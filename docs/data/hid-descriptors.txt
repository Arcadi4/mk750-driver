# MK750 HID descriptors (macOS, wired USB)

Device: `ROYUAN` / `Gaming Keyboard`, VID `0x3151`, PID `0x4015`,
bcdDevice `0x0107`, USB interface layout seen by `ioreg` / `hidapi`.

## Interfaces

| Interface | Primary usage page | Primary usage | Max input | Max output | Max feature | Purpose |
|---|---|---|---|---|---|---|
| 0 | `0x0001` | `0x06` | 8 | 1 | 0 | boot keyboard |
| 1 | `0x000C` | `0x01` | 16 | 1 | 1 | consumer + system + NKRO + mouse + vendor input |
| 2 | `0xFFFF` | `0x02` | 0 | 0 | 64 | vendor feature channel |
