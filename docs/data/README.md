# Data artifacts

Raw evidence captured from the MK750 while writing the documentation. All
files are read-only inputs for the docs; nothing here is generated by a build.

| File                   | Contents                                                                                                         |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `recon-findings.md`    | Shared brief: verified facts, exact exchanges, safety rules, reference links. Start here.                        |
| `hid-descriptors.txt`  | USB interface table and raw HID report descriptors.                                                              |
| `probe-log.txt`        | Raw stdout of the identity/settings/lighting probe run.                                                          |
| `device-state.json`    | Verified state of the unit after testing (main/side lighting, settings, profile validity) plus restore payloads. |
| `keymaps-raw.json`     | Raw hex of all 4 profiles × 8 pages for the base and Fn layers.                                                  |
| `keymap-profile0.json` | Profile 0 decoded into slot objects with `base` and `fn` entries.                                                |
| `keymap-profile0.tsv`  | Profile 0 flat table: slot, raw bytes, decoded base key, decoded Fn action.                                      |

Probe method: `hidapi` on macOS, 65-byte feature reports (leading report ID
`0x00`), Bit7 checksum for reads and Bit8 for lighting sets, 250–300 ms settle.
No keymap, macro, per-key-colour, reset, or bootloader writes were made.
